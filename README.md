## 👨‍💻 Project Description
 
This project consists of developing a professional web portfolio that integrates an **interactive 3D scene** built with Three.js. The main page presents personal information, skills, and projects, while a dedicated section allows exploration of a 3D model rendered in real time.
 
The main objective was to understand the integration of 3D graphics in modern web applications, combining **HTML5**, **advanced CSS**, and **JavaScript** to create an immersive and responsive visual experience.

## 🎨 About Three.js
 
**Three.js** is a JavaScript 3D library that simplifies the creation of 3D graphics using WebGL. It allows rendering complex models, applying textures, lighting, and creating interactive scenes directly in the browser.
 
Unlike traditional static graphics, Three.js offers complete control over cameras, lights, materials, and real-time animations — enabling sophisticated visual experiences **without the need for external plugins**.
 
🔗 Official website: [https://threejs.org](https://threejs.org)
 
---
 
## 🎥 Main Three.js Components
 
| Component | Role |
|-----------|------|
| **Scene** | Main container that houses all 3D objects |
| **Camera** | Defines the viewing perspective (`PerspectiveCamera`) |
| **Renderer** | Renders the scene on the HTML canvas |
| **Lighting** | Lighting system for visual realism |
| **Models** | Loading of external 3D models (`.glb`) |
| **Interactions** | Scene control via mouse and keyboard |

## 📂 Project Structure
 
```
web_portfolio_2026/
├── index.html              # Main entry point
├── css/
│   └── styles.css          # Global and responsive styles
├── js/
│   ├── main.js             # Main application logic
│   └── scene3d.js          # Three.js scene setup and control
├── assets/                 # Resources (models, images, etc.)
└── README.md               # This file
```
 
### File Descriptions
 
- **`index.html`** — Semantic HTML structure with navigation, content sections, and canvas for the 3D scene.
- **`styles.css`** — Responsive styles with theme system (light/dark) and CSS animations.
- **`main.js`** — Manages user interactions, navigation, dynamic theme, and background music playback.
- **`scene3d.js`** — Initializes and controls the Three.js scene with models, cameras, lighting, and optimized performance.
